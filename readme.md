# dis-rpC !

A lightweight C Rich Presence app in pure C and CLI.

## Features

* **Cross-Platform:** Designed for Windows (WinAPI) and Linux (Unix Sockets). 
*Linux part isn't done yet :')*

## How it works

* Talks to discord thanks to its IPC pipe.
