# dis rpC!

A discord rich presence tool to make it easier to share what you're doign with people !

## Description

Simple rpc app made in C, will detect software running on your computer, fully customisable status, and automations (afk, doing something specific in app...). Closing it sends it to the tray / minimises it so it doesn't pollute when you do alt+tab 'n all.

## Getting Started

### Dependencies

* None

### Installing

* Download the latest release accordingly to your needs.

### Executing program

### Linux
```
download the latest linux release and run the app executable. 
```

### Windows
```
download the standalone app.exe executable and double clic to launch.
```
